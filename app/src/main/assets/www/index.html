fcode
Version 1.0 · Part of the faiNET ecosystem
fcode is a mobile code editor for Android — write, run, and debug HTML, JSX, JavaScript, Python, CSS and more, directly on your phone with a real console and terminal.
Built and maintained by Faisal Hadawal as part of the faiNET family of apps.

faiNET Policy
Applies to fcode and other faiNET apps
Terms of Service
By using fcode you agree to use it responsibly. Code you write and files you open stay on your own device — fcode does not upload your project files anywhere.
Privacy Policy
fcode does not collect or transmit your source code, file names, or folder contents to faiNET or any third party. Running JS/Python/JSX previews may load public CDN resources (React, Babel, Pyodide) over the network to power the Run feature.
Licenses
fcode uses open-source libraries including React, Babel Standalone, Pyodide, and Font Awesome, each under their own respective licenses.
